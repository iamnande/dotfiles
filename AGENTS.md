# dotfiles agent instructions

- rfcs `MUST` go in `rfcs/NNNN-slug.md`, and `MUST` be derived from the template
  `rfcs/0000-template.md` points to

  `MUST` be submitted, approved, and merged before the original `MAY` merge.
